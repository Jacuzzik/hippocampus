Download

No release has been published yet. Until the first one, build the app from source.

Build from source (Linux)

You need Node 24, Rust, and uv (the Python tool). Then:

git clone https://github.com/Jacuzzik/hippocampus.git
cd hippocampus
uv sync
bash scripts/build-sidecar.sh
cd app
npm ci
npx tauri build

The installers are written to app/src-tauri/target/release/bundle.

Installers

Each release will list an AppImage, a .deb and an .rpm for Linux, a .dmg for macOS and an .msi for Windows, each with a SHA-256 checksum in SHA256SUMS.txt. Check the checksum before you install.

What the agents need

An agent is a command-line program you install yourself, such as Claude Code. Settings, Doctor in the app shows what is installed and signed in, and the next step for anything missing.
