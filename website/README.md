# Website

The project's website: six static pages and one stylesheet. No build step, no scripts, no cookies.

Open `index.html` in a browser to read it. `changelog.html` is made from `CHANGELOG.md`.

**Not deployed.** The plan says not to publish it until the security review is done (docs/SECURITY-REVIEW.md) and the owner says yes. Sign-in and account pages are not built: they need a hosted sign-in provider and a domain.
