    Status

    Hippocampus runs on your own computer, so there is no server to go down. This page says which version is current and what is known to be wrong.

    Current version

    0.1.0, not yet released. It is in testing before a first public beta. New versions are listed on the releases page and in the changelog.

    Build checks

    Every change runs the full test suite. See the latest results on GitHub Actions.

    Known problems

    • Builds for Windows and macOS are not ready; Linux only for now.
    • There is no sign-in yet. The app works fully without one.
    • The phone screen shown inside the app updates only when the phone's screen changes. That is how Android sends it.

    Found something not listed here? Send feedback.

    Hippocampus

    Your notes, a graph of them, and agents that work in them. Free and open source. This site sets no cookies and loads nothing from other sites.
