Security

Please report a security problem privately, not in a public issue.

Open a private advisory on the GitHub repository. The full policy, with what to include and what to expect, is in SECURITY.md.

How the app limits an agent

  • An added agent has no shell unless you switch it on, and then only inside a sandbox.
  • An agent can write only to its own outbox; the app checks who sent each message by the folder it came from.
  • Risky tools ask for your approval, and a stop button halts a running agent.
