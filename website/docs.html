Getting started

1. Choose a vault

On first run the app asks for a folder. That folder is your vault: every .md file in it is a note. You can change it later in Settings, General.

2. Add an agent

Press + Add agent in the bottom bar. Pick a name, a working folder, and the program and model it runs. The app writes its briefing and starts it in its own terminal.

3. Send a message

Open the inbox tab in the Control Room, write a message, and send it to one agent or all of them. A message is typed into the agent's terminal when the terminal is quiet.

4. The shell and the sandbox

By default an added agent has no shell. Settings, Agents has a switch that gives every agent a shell inside a sandbox (bubblewrap on Linux). The sandbox closes the app's own folder and other agents' folders.

5. When something is wrong

Settings, Doctor checks everything the app needs and says what to do for each gap. It also lists broken links between your notes.

Keyboard

Ctrl+P opens the command palette, Ctrl+O jumps to a note, Ctrl+F searches. The full list is in Settings, Keyboard.
