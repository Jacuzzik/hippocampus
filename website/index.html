Your notes, a graph of them, and agents that work in them.

Hippocampus is a desktop app. It keeps a folder of Markdown notes on your own computer, draws them as a graph, and runs real command-line agents (Claude Code and others) beside them.

Get the app Read the docs

What it does

  • Notes stay yoursPlain Markdown files in a folder you choose. No account is needed and nothing is uploaded.
  • A live graphEvery note is a dot and every [[link]] is a line. Search, filter by tag, and open a note from the graph.
  • Real agentsEach agent is its own command-line program in its own terminal, with a briefing the app writes for it.
  • Agents talk through an inboxMessages are small files. You can read every one, and write to one agent or all of them.
  • A fence around the shellWith the shell switched on, each agent runs inside a sandbox that keeps it out of the app and other agents' folders.
  • You stay in chargeToken budgets, a network switch, approval cards and a stop button are built in.

Where it runs

Linux is the tested system. macOS and Windows installers are built but not yet tested by hand; on Windows the agent terminals do not work yet.
