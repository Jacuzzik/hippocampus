01 · The graph

See how your thinking connects.

Every note is a dot and every [[link]] is a line. The graph moves as agents write, so you can watch new ideas land and find the notes nothing points to yet.

  • Search, filter by tag, and save views you come back to
  • Open a note from the graph, read it, edit it in place

04 · Yours

Runs on your computer. Your notes stay yours.

  • Plain filesMarkdown in a folder you choose. Open it in any editor, back it up any way you like.
  • Keys in the keychainAPI keys and your sign-in live in the system keychain, never in a file.
  • A network switchOff, Listen, Converse or Open, Off by default. With it off, nothing leaves the computer.
  • No account neededEverything works without one. An account is only for extras, and they are off until you turn them on.

05 · A fence around the shell

Let them run commands. Inside a sandbox.

With the shell switched on, each agent runs inside a sandbox. It can work in its own folder and your vault, and nothing else: not the app, not other agents' folders.

08 · FAQ

Questions, answered.

Is it free?

Yes. The app is free and open source. Agents that use a paid service (Claude Code, a provider key) cost what that service costs you; local models cost nothing.

Do I need an account?

No. Everything works without one. Sign in with Google only if you want share links, sync or usage history.

Where are my notes kept?

In a folder of Markdown files on your computer that you choose. They are never uploaded, even when you have an account; a share link holds only the one note you share, until it expires.

Can I use it with my Obsidian vault?

Yes. A vault is a folder of Markdown notes with [[links]], which is what Hippocampus reads.

Can an agent break my computer?

The shell is off by default. When you switch it on, each agent runs in a sandbox that keeps it to its own folder and your vault, and risky steps wait for your approval.

Which systems does it run on?

Linux is tested. macOS and Windows installers are built but not yet tested by hand; on Windows the agent terminals do not work yet.
