Order of work for the final build
1. Stability first (section A): error boundary, sidecar watchdog, one terminal component, timers
   cleaned up. Nothing else starts until these pass.
2. Fix the terminal garble (section 1, rows 1-2) with a screenshot check, then fonts (section 6):
   bundle the monospace font and switch the token.
3. UI tokens and shared components (sections 3, 5): theme tokens, Button, Dialog, PanelHeader. Then
   alignment fixes (section 4).
4. Backend cleaning (section 11): split the big file, logging, error envelope, supervised sidecar,
   indexer debounce.
5. Inbox / outbox (section 9) and briefings (section 8) together: they share one message schema.
6. Shell for all agents with the sandbox (section 10), tested before it is turned on.
7. Motion and loading (sections 12, 13) on top of the shared components.
8. Munder Difflin feature set (section 7), in this order: circuit breaker, budgets view, kanban,
   automations, IDE. Office floors are dropped (no simulator). Then the original features in section
   N, starting with Recall bar, Spend ribbon, Doctor page and Crash-safe sessions.
9. Shared Tab, EmptyState, PlaceholderPanel and setting-row components (sections K, L, M), then the
   new Settings page with one schema; Control panel becomes Operations.
0. Connectors (section K): registry and cards first, then Slack, webhooks and missions, then MCP and
   GitHub; every unfinished one stays a Planned placeholder.
1. Account system and website (sections 14, 15) last: they add public risk and need a security
   review.
2. Release: tests on Node 24, screenshots, clean-machine install, tag, GitHub push, launch (sections
   C, D, G, I).
